## 🧠 Python Projesi Açıklaması
Bu projede Python programlama dili kullanılarak **otomatik HTML sayfası oluşturan** bir program geliştirilmiştir.

Program:
- Konsol üzerinden kullanıcıya sorular sorar  
  - Ad – Soyad  
  - Alınan dersler  
  - Kısa biyografi  
- Kullanıcının girdiği bilgilerle **index.html** adlı bir dosya oluşturur
- Oluşturulan HTML dosyası:
  - Başlık içerir
  - Liste yapısı kullanır
  - Basit CSS ile renklendirilmiştir
